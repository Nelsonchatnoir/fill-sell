compte connu étranger. Effet immédiat en prod : 0 tâche (aucune tâche eBay ouverte sur un compte non France aujourd'hui).

  une seule vérité « eBay de ce pays prouvé », qui ouvre aussi l'app aux vendeurs GB/US). eBay France toujours ouvert.
  Aucune clé `ebay_*` en prod aujourd'hui (lu 13/11). Sans migration. Un interrupteur posé trop tôt n'ouvre rien (verrou).
  Alternative si Nico veut découpler app et serveur : `ebay_site_<cc>`.
- **Reprise** (`reprendreAttentesSiteEbay`, worker l.389, à chaque passage avant la sortie anticipée, 100 au plus) : compte
  relié sur eBay France, ou site ouvert → pending (levée tracée) ; publication voie extension d'un compte relié → voie api ;
  liaison révoquée ou déliée → message « Relie ton eBay à FillSell » (une écriture) ; sinon rien. Doute (site non lu) : attend.
- **Retenter** : la relance remet la tâche en file ; le worker la remet en attente (date de début gardée) — jamais close.
- **D10** (`get-pending-jobs` l.4262-4310, bloc eBay existant) : publication/republication eBay voie extension d'un compte dont
  `ebay_accounts.ebay_site` (même révoqué) ≠ France → jamais servie ; mise en attente (« relie ton eBay à FillSell » si pas
  relié) ; publication d'un compte relié → l'API (inchangé). Compte FRANÇAIS ou SANS liaison API → servi sur ebay.fr comme avant.
  **Peut-on savoir qu'un compte eBay de l'extension est étranger ?** Seulement par la liaison API (GetUser `<Site>`). La sonde
  de l'extension (`background.js:14942-14990`) ne lit qu'une session sur ebay.fr, aucune identité ; ventes eBay des comptes
  sans API : devise nulle (29 ventes, 6 comptes) ; adresse/pays du poste ne prouvent pas le site (c7c382b7 : objet en France,

## 6. Risques
- Une republication voie extension d'un compte étranger (annonce créée par le formulaire ebay.fr) n'a pas de route API : elle
  attend, même site ouvert (L3) — 0 aujourd'hui.
- L'attente garde la réservation/quota « hors quota » (comme la clôture d'avant) et reste hors quota si elle part plus tard
  (précédent : `ebay-reouverture.ts`). Elle bloque une 2e publication eBay du même article (conflit RPC) : voulu (pas de doublon).
- `SITES_EBAY_PUBLIABLES` ne doit grandir qu'avec le code L2/L4 (sinon le worker publierait sur EBAY_FR).
- Relance d'une tâche dont la liaison a été supprimée : la marque garde le site, la tâche attend avec « relie ton eBay ».
